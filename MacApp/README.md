# 영상 검수 도우미 (macOS)

로컬 MP4/MOV/M4V를 열어 컷, 디졸브, 화면 자막 변화 후보를 자동 검출하는 네이티브 macOS 앱입니다.

## 기능

- 앱 아이콘 더블클릭 실행
- 여러 파일 선택 또는 드래그앤드롭 후 순차 분석
- 탭별 검수 결과와 별도 분석 상태 창
- 앱 재실행 시 작업 목록과 완료 결과 복원
- 앱 안에서 영상 재생 및 마커 통합 재생바 탐색
- Space 재생/일시정지, ←/→ 3초 이동
- Q/↓ 감속, W 정속, E/↑ 가속 재생(0.1×~10×, 피치 유지)
- 컷/디졸브/자막 변화 후보와 신뢰도 표시
- 같은 장면·유사 자막의 반복 검출 억제
- 통합 LUFS 및 sample peak 측정, YouTube 실무 기준 판정
- 성경 장·절 자막 인식 및 대한성서공회 개역개정 바로가기
- 색상 타임라인 마커 및 썸네일
- 후보 클릭 시 해당 시점으로 이동
- 결과 JSON 내보내기
- 네트워크 전송 없음
- Python, ffmpeg 등 별도 설치 불필요

음량 적합 여부는 YouTube가 공개한 공식 목표값이 아니라 널리 쓰이는 실무 기준(-14 ±1 LUFS, sample peak ≤ -1 dBFS)을 사용합니다.

## 빌드

```bash
./MacApp/build.sh
```

완성된 앱과 DMG는 `dist/`에 생성됩니다.

## 팀 배포

현재 DMG는 임시(ad-hoc) 서명되어 있습니다. 다른 Mac에서는 처음 한 번 앱을 Control-클릭 → **열기**로 실행해야 할 수 있습니다. 경고 없이 배포하려면 Apple Developer ID 인증서로 서명하고 Apple 공증(notarization)을 받아야 합니다.
